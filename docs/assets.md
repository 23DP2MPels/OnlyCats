# Изображения и логотип

Логотип `frontend/public/cat-logo.svg` — собственный векторный знак: кошачья
мордочка с ушами и усами. Используется в шапке, подвале и favicon.
SVG-иллюстрации остаются у Оливера и Моти, а у Мармелада и Луны — настоящие фото.

Фотографии скачаны для локальной раздачи приложением; внешняя загрузка при
просмотре страниц не нужна. Источники и авторы:

| Файл                 | Автор        | Источник                                                                                                       |
| -------------------- | ------------ | -------------------------------------------------------------------------------------------------------------- |
| `cats/marmalade.jpg` | engin akyurt | [A happy orange cat enjoys the sun](https://unsplash.com/photos/a-happy-orange-cat-enjoys-the-sun-FH083rEEXcs) |
| `cats/luna.jpg`      | Omar Ramadan | [Russian blue cat](https://unsplash.com/photos/OUZa0RDXnjw)                                                    |

Обе фотографии распространяются по [Unsplash License](https://unsplash.com/license).
Это общедоступные демонстрационные материалы. Они не являются эксклюзивными
фотографиями авторов страниц; настоящие приватные фото загружаются владельцем.
Генератор SVG не заменяет скачанные фотографии и логотип.
