# Attēli un logotips

Logotips `frontend/public/cat-logo.svg` ir pašu veidota vektorzīme: kaķa seja
ar ausīm un ūsām. To izmanto galvenē, kājenē un vietnes ikonā.
Oliveram un Motjai saglabātas SVG ilustrācijas, bet Marmelādam un Lunai ir īsti fotoattēli.

Fotoattēli ir lejupielādēti un tiek izsniegti lokāli; lapu apskatei nav vajadzīga
attēlu ielāde no ārējiem avotiem. Avoti un autori:

| Fails                | Autors       | Avots                                                                                               |
| -------------------- | ------------ | --------------------------------------------------------------------------------------------------- |
| `cats/marmalade.jpg` | engin akyurt | [Ruds kaķis bauda sauli](https://unsplash.com/photos/a-happy-orange-cat-enjoys-the-sun-FH083rEEXcs) |
| `cats/luna.jpg`      | Omar Ramadan | [Krievu zilais kaķis](https://unsplash.com/photos/OUZa0RDXnjw)                                      |

Abiem fotoattēliem piemēro [Unsplash licenci](https://unsplash.com/license).
Tie ir publiski pieejami demonstrācijas materiāli, nevis profilu autoru ekskluzīvi
fotoattēli. Īstos privātos fotoattēlus augšupielādē īpašnieks.
SVG ģenerators neaizstāj lejupielādētos fotoattēlus un logotipu.
