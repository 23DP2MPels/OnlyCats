# Интерфейс OnlyCats

Тёплая нейтральная палитра, коралловый акцент и собственные SVG-коты.
Иллюстрации воспроизводятся командой `node devops/generate-art.mjs`.
Шрифты загружаются из Google Fonts, при недоступности используются системные.

Интерфейс поддерживает латышский (по умолчанию), русский и английский языки.
Переключатель LV/RU/EN находится в шапке. Словари лежат в `src/locales/`,
реактивная локаль и локализованные ошибки — в `src/i18n.ts`.
Даты форматируются через Intl для выбранной локали. Пользовательский контент
сохраняется на языке автора. Полнота словарей проверяется `npm test -w frontend`.

Кнопка солнца/луны переключает светлую и тёмную темы. При первом открытии
учитывается тема системы, затем — сохранённый выбор. Язык и тема сохраняются
в localStorage. Цвета заданы семантическими CSS-переменными. Используются
Manrope для основного текста и Lora для акцентов, с поддержкой всех трёх языков.

Страницы: каталог, профиль кота, вход/регистрация, личный кабинет, результат
PayPal и 404. Навигация использует Vue Router; Nginx возвращает index.html
для вложенных маршрутов. API-клиент работает через относительный `/api`.

Сессия хранится на серверной стороне браузерного протокола в HttpOnly cookie:
Vue не читает JWT. После входа обновляется реактивное состояние пользователя.
Формы показывают ошибки, блокируют повторное нажатие при выполнении запроса.
В случае неудачной загрузки фото редактор сохраняет ID уже созданной публикации,
чтобы повторная попытка не создавала дубликат.

Приватный пост отображается карточкой с предложением подписки. Сервер не
передаёт его тело или изображение: CSS-размытие не используется как защита.
Переход к оплате допускает только HTTPS-ссылку www.sandbox.paypal.com.

Макет адаптируется к узким экранам, формы имеют label, кнопки — состояния
disabled и видимый focus. При prefers-reduced-motion анимация отключается.
