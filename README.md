# OnlyCats

Учебный проект: NestJS, Vue, Prisma и PostgreSQL. Только PayPal Sandbox.

Реализация MVP находится в ветке `feat/onlycats-mvp` и проходит проверку в PR.

История оформляется ретроспективно с согласованными авторами и датами этапов;
она не подтверждает фактическую работу участников в указанные дни.
